Auch für deine Webseite

Eine Zeile.
Alle Schriften.

Die CSS-Datei bindet Avela als Webfont ein. Der Browser lädt nur die verwendeten Schnitte. Du kannst die Dateien auch auf deinem eigenen Server ablegen.

Anleitung und Beispiele ↗

In den HTML-Kopf einfügen

<link rel="stylesheet"
  href="https://christianurff.github.io/avela/web/avela.css">

In deiner CSS-Datei

body {
  font-family: "Avela Buch", sans-serif;
}
.rechnen {
  font-family: "Avela Rechnen", sans-serif;
  font-feature-settings: "calt" 1;
}

Frei nutzbar. Klar gekennzeichnet.
